# Archived design direction — Traqo Soft Workspace

This file preserves the superseded neumorphic direction from August 2026.

- Background/surface: `#E8EDF3`, `#EEF3F8`, and `#DFE5EC`.
- Brand action: burnt orange `#C94E27`.
- Visual model: raised and inset surfaces using paired light/dark shadows.
- Components: rounded cards, tactile buttons, inset inputs, elevated navigation.
- Typography: Space Grotesk with Fira Code metadata.
- Main constraint: use soft depth for hierarchy while keeping dense task content flatter.

This direction was retired because the product is a document workspace. Persistent elevation made large roadmaps feel visually noisy and made every task appear equally important. The replacement system is defined in `design.md`.
